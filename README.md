13 years waiting for GTA 6, 3 hours for the download — my agent got paid on make.fun before it finished. A GTA 6 meme with make.fun's ghost mascot sitting on the couch beside a tired gamer in Leonida, posted on X for make.fun's "Post a GTA 6 meme on X" bounty. The post itself is the entry: the house reads its first picture and text from X and an AI judge ranks the posts. This repository hands in the post's address in POST.json; main.ts validates that address and copies the file to the output directory for the gate.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then `out/POST.json` is byte for byte this repository's `POST.json`.
